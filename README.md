# POE2 Triple Arbitrage Finder

## In Rust!

Uses the official GGG API to identify both arbitrage and market making opportunities.

I wrote this in rust because I enjoy writing rust. I should not have written this in rust. I should have
written this in Python or Node.js or Ruby or something that makes more sense for a web backend.

I'm writing this with Tauri to learn Tauri. I should not be writing this with Tauri. I should probably be writing this as a generic webapp.

I'm writing the front end with React because everyone and their mother uses React for everything and I've never used React. There's no other reason and React is likely hugely overkill for what I need.

The "best" stack is probably either Python/vanilla TS or full stack TS as opposed to rust.

Also this won't work for you because you need your own GGG api keys for leagues and the currency exchange. Maybe in the future I'll have somewhere for you to put them in.

I am learning a lot with this project.
